# TokyoMotion Catalog

TokyoMotionの公開メタデータと公式埋め込みURLを使うGitHub Pagesカタログです。動画ファイルの保存・コピー・中継はしません。カードをタップすると、そのカードのサムネイル位置で再生する形式です。別窓・モーダルは開きません。

## 初回設定

1. **Settings → Pages → Source** を **GitHub Actions** にする
2. **Actions** から `Update TokyoMotion catalog` を一度手動実行する
3. `Deploy TokyoMotion catalog` が完了するとPagesに反映される

GitHub Actionsに30分間隔の定期実行を設定しています。実行時刻はGitHub側の混雑などで遅れる場合があります。更新ボタンは公開済みのJSONを再読み込みするもので、収集を直接開始するボタンではありません。

## 取得と表示

- RSSと最新一覧の1〜6ページを毎回確認します。
- 過去の一覧は1回12ページずつ、`backfill.nextPage`に記録された続きから進めます。失敗したページは飛ばしません。
- 既存作品を保持しながら追加します。総件数を100件に切り詰める処理はありません。全過去作品の取得完了を保証するものではありません。
- 詳細取得は負荷を抑えるため1回最大240作品・逐次アクセスです。各アクセス後に待機し、拒否・レート制限があればその回の追加アクセスを止めます。新規・未取得を補完し、既存情報も一定時間後に再確認します。
- 古い誤解析値は無効化して再取得します。数字が確認できない場合は「未取得」で、0や推測値に置き換えません。
- 評価率（%）と高評価・低評価の票数を区別します。数字は最終取得時点の公式掲載値です。
- 票数は公式ページの`video_likes`・`video_dislikes`から取得します。解析方法の更新前の作品も再監査します。
- 404の作品は一覧に残し、利用できなくなった埋め込みを外します。毎回の連続再試行を避け、一定時間後に再確認します。
- 相対日付しか公開されない作品は概算日付となり「頃」を付けます。
- 一覧は36件ずつ追加表示します。追加時は既存カードを作り直さず、再生を維持します。検索・並び替えは読み込んだ全件を対象にします。
- 黒基調の検索・サイドメニュー・カード一覧に、人気作品の横スクロール棚を組み合わせています。他社のロゴは使用していません。
- 再生するカードは同時に1つです。別のカードを開く・一覧条件を変更する・再生を閉じると前のiframeを破棄します。モバイルでは再生中のカードを一覧の横幅いっぱいに拡大します。
- 初回の独自年齢確認オーバーレイはありません。公式側の年齢・地域・認証制限は変更しません。

公式プレイヤー枠の表示・埋め込みURLの取得と、動画の実再生成功は別です。公式プレイヤーや端末が自動再生を許可しない場合は、カード内の再生ボタンを押す必要があります。削除・非公開・配信制限や通信障害がある場合は再生できません。再読み込みと公式作品ページへのリンクを用意しています。アクセス拒否時の制限回避は行いません。

## 日本語タイトルのみ

取得時と画面表示時で同じ`assets/language.mjs`を使います。英語・中国語のタイトルを除外し、既存作品にも毎回適用します。自動翻訳は行いません。英語の説明文中に日本語が少し混ざる場合や、中国語の特徴がある混在タイトルも除外します。

漢字だけのタイトルは日本語・中国語を確定できないため、保守的に除外します。作品番号だけのものも表示しません。日本語のタイトルに含まれるFC2等の番号・画質表記は許可します。この判定は作品タイトルの言語であり、動画内の音声言語や出演者の属性を判定するものではありません。完全な言語識別は保証できません。

除外件数はJSONの`languagePolicy`に理由別で記録します。タイトル本文や動画は保存し直しません。公開カタログから削除された既存データはGitの以前のコミットから復元可能です。

## テスト

```sh
node --test tests/catalog.test.mjs
```

中立的なテスト用メタデータで解析、既存100件からの新着追加、巡回再開、取得失敗時の保持、UIの欠損値処理を確認します。収集の実行結果はActionsログと`data/videos.json`の`summary`・`errors`・`backfill`に記録します。

## 注意

TokyoMotionの利用規約に従い、個人・非商用の公式埋め込み用途を前提にしています。公式プレイヤーの改変や動画の保存・再配布は行いません。
